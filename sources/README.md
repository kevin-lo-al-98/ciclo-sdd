# Fuentes

Documentación oficial y referencias de calidad. El criterio para que algo entre aquí es
que sea **fuente primaria** o material que se mantiene actualizado. Los tutoriales
sueltos envejecen mal y no van en esta lista.

## Claude

- [Documentación de Claude](https://docs.claude.com) — API, modelos, capacidades.
- [Modelos y precios](https://www.anthropic.com/pricing) — la referencia de coste.
- [Claude Code](https://code.claude.com/docs) — CLI, hooks, skills, MCP, comandos.
- [Agent SDK](https://code.claude.com/docs/en/agent-sdk) — construir agentes propios.

## Git

- [Conventional Commits](https://www.conventionalcommits.org/es/v1.0.0/) — la
  especificación, en español.
- [git worktree](https://git-scm.com/docs/git-worktree) — la página de manual; el
  apartado "DETAILS" es el que explica qué se comparte entre worktrees y qué no.

## TypeScript

- [Manual de TypeScript](https://www.typescriptlang.org/docs/handbook/intro.html)
- [Referencia de tsconfig](https://www.typescriptlang.org/tsconfig/) — qué activa
  exactamente cada flag del perfil estricto.
- [Type Challenges](https://github.com/type-challenges/type-challenges) — para el
  sistema de tipos avanzado, mediante ejercicios.

## React

- [react.dev](https://react.dev) — la documentación oficial actual. Ignora la antigua
  (`reactjs.org`): enseña patrones de clase ya superados.
- [Separar useEffect de lo que no lo necesita](https://react.dev/learn/you-might-not-need-an-effect)
  — corrige el error más extendido en React.
- [TanStack Query](https://tanstack.com/query/latest) — estado de servidor.
